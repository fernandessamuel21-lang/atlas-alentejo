# Atlas Alentejo — Território e Água

Atlas 3D interativo das regiões hidrográficas do Sado e Mira (RH6) e do Guadiana (RH7), em Portugal.

**Ver o atlas:** https://fernandessamuel21-lang.github.io/atlas-alentejo/

Este repositório contém apenas a distribuição estática do atlas, gerada a partir de um pipeline Python separado.
